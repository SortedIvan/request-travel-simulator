# request-travel-simulator
A cool little project of *imaginary* request travelling from point A to point B.

There are several constructs:
- Producers: Produce a single random colored packet
- Mergers: Merge two packets into one
- Color flip: Flip color to another randomized color packet
- Void: End node, sink
- Splitter: Split a packet into multiple
